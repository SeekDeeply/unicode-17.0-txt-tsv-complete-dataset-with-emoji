# Changelog

## Unreleased - dataset is now generated, not hand-maintained

Every file in this repository is rebuilt from the official UCD and Emoji sources
by `src/build.mjs`, and `src/verify.mjs` proves the result is complete. See
[docs/PIPELINE.md](docs/PIPELINE.md) for the reasoning behind each change below.

### Fixed

- **17,343 assigned code points were missing.** `UnicodeData.txt` brackets the
  Hangul, Tangut and CJK ranges with `<First>`/`<Last>` markers instead of listing
  them. Those ranges were carried over as boundaries only, so U+AC01..U+D7A2
  (11,170 Hangul syllables), U+17001..U+187FE (6,142 Tangut ideographs) and
  U+18D01..U+18D1D (29 more) never reached a dataset that advertises itself as
  complete. They are now expanded, one row each, with their algorithmic names.
- **The character TSV was structurally broken.** U+0009 and U+000A were written
  literally into a tab-separated file: U+000A split its row across two lines and
  U+0009 produced a fourth column. The file claimed 142,610 rows and no TSV parser
  could read it as such. The raw character column is replaced by a lossless
  `escaped` column, and the verifier asserts every row has exactly 9 fields.
- **Two emoji rows were silently deleted.** Keycap sequences render as `#️⃣`
  and `#⃣`, so a leading-hash comment filter dropped both. Comment detection is
  now explicit and unit-tested.
- **Lone surrogates were written into UTF-8 files.** Encoding them produced U+FFFD
  and corrupted the value. They are now escaped in `escaped` and shown as a
  placeholder in `char`.
- **Two single-line files were not single-line.** `unicode_*_string.txt` contained
  raw LF and CR, so `wc -l` reported 0 and line-oriented tools mangled it.
- **Noncharacters were mislabelled** with a block name that does not describe them;
  they now carry their real block plus `type=noncharacter`.
- **README statistics did not match the files.** Every count is now generated from
  `data/manifest.json` by `src/render-docs.mjs`.

### Added

- `src/` - the collection and generation pipeline (Node >= 20, no dependencies).
- `src/verify.mjs` - 155 independent checks, re-derived from the upstream sources.
- Unit tests for every parser: `npm test`.
- `data/sources.lock.json` - SHA-256 of every upstream file, so a silent upstream
  change fails the build instead of changing the data.
- `data/manifest.json` - sizes, line counts, hashes and headline counts of every
  output file.
- Three GitHub Actions workflows: build & verify on every push, a weekly upstream
  release check that opens a tracking issue, and release publishing on tags.

### Changed

- Output paths are derived from the version constants in `src/lib/sources.mjs`.
- The build is byte-reproducible: the timestamp comes from a pin, not the clock.
- `checksum_sha256.txt` now covers every data file and is regenerated by the build.
- The emoji TSV gained `group` and `subgroup` columns.

### Removed

- `Screenshots/` - the four images depicted the previous layout, including the
  broken TSV. They could not be regenerated here (no browser available) and
  screenshots that no longer show the shipped files mislead rather than help.
  Every claim they supported is now enforced by `npm run verify`.
