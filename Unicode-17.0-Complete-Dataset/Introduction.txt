1. unicode_17.0_machine.tsv
   (18.10 MB, 159,961 lines)
   Machine readable: 9 tab-separated columns, exactly one line per code point.

     code_point   U+XXXX or U+XXXXXX
     char         the character as a display aid (controls appear as a dot)
     escaped      lossless form: backslash-t, backslash-n, backslash-r or \u{XXXX}
     name         Name property, algorithmic names expanded
     category     General_Category (Lu, Lo, Cc, Cn, Co, Cs, ...)
     block        block name, English
     block_zh     block name, Chinese
     script       Script property
     type         assigned | control | noncharacter | surrogate | private-use

   Why the escaped column exists: TAB and LINE FEED cannot be written literally
   inside a TSV cell - TAB creates an extra column, LF splits the row. Writing
   them raw, as an earlier revision of this dataset did, makes the file
   unparseable even though it looks fine in an editor.
