  render as hash + variation selector + combining enclosing keycap:

     0023 FE0F 20E3   fully-qualified   keycap: #
     0023 20E3        unqualified       keycap: #

  A parser that skips every line starting with the hash character loses both.
  Skip only a bare hash line, a line starting with hash+space, or hash+tab.
